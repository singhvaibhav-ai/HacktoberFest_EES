Read a year and print `YES` if it is a leap year, otherwise print `NO`.

A year is a leap year if:

- it is divisible by `400`, or
- it is divisible by `4` but **not** by `100`.

### Input

A single integer `year` (1 ≤ year ≤ 10⁹).

### Output

Print `YES` if the year is a leap year, otherwise print `NO`.

### Example

**Input**
```
2024
```

**Output**
```
YES
```

### Notes

- `1900` is **not** a leap year: it is divisible by `100` but not by `400`.
- `2000` **is** a leap year because it is divisible by `400`.
