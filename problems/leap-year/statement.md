Print `YES` if the given year is a leap year, otherwise `NO`. A year is a leap year if it is divisible by 4, except years divisible by 100, unless they are also divisible by 400.

### Input

A single integer `y` (1 ≤ y ≤ 9999).

### Output

`YES` or `NO`.

### Example

**Input**
```
2024
```

**Output**
```
YES
```
