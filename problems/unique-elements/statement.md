Given an array of integers, output all the unique elements in the array. Each unique integer should be printed on its own line.

The elements can be printed in **any order**.

### Input

- The first line contains an integer $n$ ($1 \le n \le 10^5$), the size of the array.
- The second line contains $n$ space-separated integers $a_1, a_2, \ldots, a_n$ ($-10^9 \le a_i \le 10^9$).

### Output

Print each distinct integer on a new line, in any order.

### Example

**Input**
```
5
2 3 2 1 3
```

**Output**
```
1
2
3
```
