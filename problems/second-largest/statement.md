Given `n` integers, print the second largest **distinct** value. Repeated values count only once, so `[10, 10, 9]` has second largest `9`.

### Input

The first line contains `n` (2 ≤ n ≤ 10⁵). The second line contains `n` integers, each between −10⁹ and 10⁹. There are always at least two distinct values.

### Output

The second largest distinct value.

### Example

**Input**
```
5
3 1 4 1 5
```

**Output**
```
4
```
