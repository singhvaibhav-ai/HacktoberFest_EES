Given the coordinates of two 2D points $(x_1, y_1)$ and $(x_2, y_2)$, calculate the Euclidean distance between them:

$$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

### Input

A single line containing four numbers $x_1$, $y_1$, $x_2$, and $y_2$ ($-10^4 \le x_1, y_1, x_2, y_2 \le 10^4$).

### Output

Print a single number, the distance between the two points. Answers within $10^{-6}$ of the expected answer will be accepted.

### Example

**Input**
```
0 0 3 4
```

**Output**
```
5.0
```
