Read one line of text and print it reversed.

### Input

A single line of text (1 ≤ length ≤ 10⁵). The line may contain uppercase and lowercase letters, digits, spaces and punctuation.

### Output

Print the same line with its characters in reverse order.

### Example

**Input**
```
hello
```

**Output**
```
olleh
```

### Notes

- Spaces are characters too, so they keep their reversed positions.
- For example, `hello world` becomes `dlrow olleh`.
- The input has exactly one line, so read the whole line rather than a single word.
