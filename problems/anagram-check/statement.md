Two words are anagrams if they use exactly the same letters, the same number of times, in any order. Print `YES` if the two lines are anagrams, otherwise `NO`.

### Input

Two lines, each a word of lowercase letters (up to 1000 characters each).

### Output

`YES` or `NO`.

### Example

**Input**
```
listen
silent
```

**Output**
```
YES
```
