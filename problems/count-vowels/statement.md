Given a line of text, count and print the total number of vowels (`a`, `e`, `i`, `o`, `u`, case-insensitive).

### Input

A single line containing string `s` ($1 \le |s| \le 10^5$).

### Output

Print a single integer: the count of vowels.

### Example

**Input**
```
Hello World
```

**Output**
```
3
```
