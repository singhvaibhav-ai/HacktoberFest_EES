Read one line of text and print how many vowels it contains.

The vowels are `a`, `e`, `i`, `o` and `u`. Count both uppercase and lowercase letters.

### Input

One line of text. The line may be empty and can contain letters, digits, spaces and punctuation.

### Output

Print a single integer, the number of vowels in the line.

### Example

**Input**
```
Hacktoberfest
```

**Output**
```
4
```
