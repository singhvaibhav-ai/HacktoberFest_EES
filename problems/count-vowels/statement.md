Read one line of text and print how many vowels it contains.

The vowels are `a`, `e`, `i`, `o` and `u`. Count both lowercase and uppercase vowels. The letter `y` is **not** a vowel for this problem.

### Input

A single line of text (at most 1000 characters).

### Output

A single integer: the number of vowels in the line.

### Example

**Input**
```
Hello, World!
```

**Output**
```
3
```
